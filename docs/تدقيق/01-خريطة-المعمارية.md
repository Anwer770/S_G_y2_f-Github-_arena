# 01 — خريطة المعمارية (As-Is Architecture Map)

> مبنية على مسح فعلي لكل ملفات `src` (227 ملفاً) — تُحدَّث آلياً بتشغيل `python3 tools/audit/audit.py`.

## 1) نقطة الدخول وسلسلة التركيب
```
index.html
  └── src/main.tsx                     StrictMode → ThemeProvider → App
        └── src/App.tsx                AppProviders → MainApp
              ├── src/app/providers/AppProviders.tsx   (AuthProvider + Theme)
              ├── src/app/App.tsx     «قلب التطبيق»: كل الحالة + 25 معالج CRUD
              │     └── src/app/layouts/MainLayout.tsx  Sidebar + Header + محتوى

              └── src/components/**   الوحدات والمكونات
```

## 4) تدفّق البيانات — المساران المتوازيان (جوهر المشكلة المعمارية)
```
[حديث]  Component → service (XService) → repository (BaseRepository) ─┐
                                                                      ├─→ indexedDBStorage
[قديم]  Component/App.tsx → utils/storage.ts load*/save* → dbStorage ─┘        │
                                                                               ▼
                                                        getItemSync / setItemSync   ← متزامنة!
                                                                               │
                        ┌──────────────────────────────────────────────────────┤
                        ▼                        ▼                             ▼
                 memoryCache            IndexedDB store             localStorage (مرآة <500KB)
```
**نتيجتان مقاستان:**
1. **R1** — كل الاستدعاءات متزامنة ولا تنتظر `initPromise` ⇒ أول قراءة بعد إقلاع بارد قد تكون `null` ⇒ سقوط على `DEFAULT_*`/`INITIAL_*` (43 موضعاً) ⇒ أول حفظ يستبدل البيانات الحقيقية.
2. **R2** — كل كتابة عبر الخدمات تُضيف عنصراً كاملاً إلى `suite_sync_outbox_v1` ولا يوجد مُفرِّغ.

## 5) الأمان والصلاحيات
- حارس واجهة فعّال: `AppRouter` يمنع عرض وحدة غير مصرّح بها (`canAccessModule`) بناءً على `ROLE_MODULE_ACCESS` في `AuthContext`.
- لكن المنطق كله في المتصفح: الجلسة والمستخدمون و`pin` في التخزين المحلي، وقبول `1234` لأي حساب (R3).
- لا اتصال بأي API خارجي: التطبيق **يعمل بالكامل محلياً** (لا `fetch` في الشيفرة). `@google/genai` معرّف في `package.json` وغير مستخدم (0 استيراد) — طبقة AI **غير موجودة** فعلياً رغم ذكرها في الوصف.

## 6) التصميم والواجهة (حقائق قابلة للقياس)
- RTL كامل (`dir="rtl"` على `html` + CSS)، خط Cairo.
- وضعان: فاتح/ليلي عبر `class="dark"` — تغطية غير متساوية (WorkOS 0%, العملاء 5%, الأطباء 5%, الديون 9%).
- استجابة: `sm:` 369 · `md:` 160 · `lg:` 100 · `xl:` 6 · `2xl:` 0 — أي التفكير الجوّالي يبدأ من 640px فما فوق فقط.
- الطباعة: أنماط `@media print` موجودة في `index.css` بلا مقاس `@page` ولا ترقيم صفحات.
